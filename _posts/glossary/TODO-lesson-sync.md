# 용어 사전 — 회차 싱크 대기 목록

수업 리뷰 글이 아직 없어서 `lesson: 0`으로 둔 용어들.
**앞으로 올라올 회차 리뷰와 연관이 있을 예정**이므로, 리뷰가 올라오면 아래를 같이 고친다.

1. front matter `lesson:` 값을 실제 회차 숫자로
2. 본문 `## 3. 어디서 만났나` — 지금은 "이어지는 회차로 맥락 링크"만 걸려 있음.
   실제로 배운 회차 리뷰 글 링크를 맨 앞에 추가하고, 도입 문장을 고칠 것
   ("수업에서 정식으로 다루기 전에 따로 정리한 것이다" → 실제 맥락으로)
3. 다 고쳤으면 본문 맨 위 `<!-- TODO: 회차 확정 -->` 주석을 지울 것

링크 형식: `[N회차 — 제목]({{ site.baseurl }}/YYYY/MM/DD/슬러그/)`

## 아직 글이 없는데 다른 글에서 링크를 걸어 둔 용어

글을 만들면 자동으로 링크가 걸린다. `term` 값을 아래 표기와 정확히 맞출 것.

**AI 기초** — 어텐션 · 트랜스포머 · 로짓
**개발환경** — 터미널 · 셸 · PowerShell
**웹 / 데이터** — 데이터베이스 · SQL · JSON
**Git** — 저장소
**에이전트** — PRD · 바이브 코딩 · 스코프 크립
**기타** — 절대 경로 · 배포 · 환경 변수

### 표기 통일이 필요한 것

`LLM` 글의 `related`에 **`Transformer`**(영문)가 들어 있는데,
`Q/K/V` 글에는 **`트랜스포머`**(한글)로 걸려 있다.
「트랜스포머」 글을 만들 때 `term` 값을 어느 쪽으로 할지 정하고,
다른 글의 `related`와 `{% include term.html %}` 표기도 함께 맞출 것.
