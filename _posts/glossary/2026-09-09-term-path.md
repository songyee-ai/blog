## 한 줄 정의

> 운영체제가 실행 파일을 찾을 때 검색하는 디렉터리 경로를 저장한 환경 변수

---

## 1. 비유로 이해하기

PATH는 **“이 프로그램 어디에 있는지 알려주는 주소록”**이라고 생각하면 이해하기 쉽다.

컴퓨터에 프로그램을 설치하면 실행 파일이 특정 폴더에 저장된다.

예를 들어 Node.js를 설치했는데 실행 파일이

`C:\Program Files\nodejs\`

에 있다고 해보자.

터미널에서 매번

`C:\Program Files\nodejs\node.exe`

처럼 전체 경로를 입력하는 것은 불편하다.

그래서 운영체제에는 **“프로그램을 찾을 때 이 폴더들도 찾아봐”**라고 미리 알려주는 목록이 있다. 이것이 `PATH` 환경 변수다.

PATH에 해당 폴더가 등록되어 있으면 터미널에서

`node`

처럼 프로그램 이름만 입력해도 운영체제가 PATH에 등록된 폴더들을 차례대로 확인해서 해당 실행 파일을 찾아 실행할 수 있다.

비유하면,

**PATH가 없다면 → “정확한 주소를 알려줘야 찾아가는 상황”**

**PATH가 있다면 → “주소록에서 이름을 검색해서 찾아가는 상황”**

이라고 볼 수 있다.

---

## 2. 왜 필요한가

개발을 하다 보면 `node`, `npm`, `git`처럼 터미널에서 직접 실행하는 프로그램이 많다.

이때 실행 파일의 전체 경로를 매번 입력하지 않고 프로그램 이름만으로 실행하려면 운영체제가 그 프로그램의 위치를 알아야 한다.

PATH는 바로 이 문제를 해결한다.

예를 들어 Node.js를 설치한 뒤 터미널에서

```bash
node --version
```

을 입력했을 때 Node.js의 버전이 출력된다면, 운영체제가 PATH를 통해 `node` 실행 파일을 찾을 수 있다는 뜻이다.

반대로

```text
'node'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램 또는
배치 파일이 아닙니다.
```

같은 오류가 발생한다면 Node.js가 설치되지 않았거나, 설치는 되어 있지만 실행 파일이 있는 경로가 PATH에 제대로 등록되지 않았을 가능성이 있다.

따라서 개발환경을 처음 설정할 때 PATH를 이해하면 **“프로그램은 설치했는데 왜 터미널에서는 명령어가 안 먹지?”** 같은 문제를 해결하는 데 도움이 된다.

## 4. 헷갈리는 개념

| 이 용어 | 비슷하지만 다른 것 | 차이 |
| --- | --- | --- |
| PATH | 환경 변수 | PATH는 환경 변수의 한 종류다. 환경 변수는 프로그램의 실행 환경에서 사용할 여러 값을 저장하고, PATH는 그중 실행 파일을 찾을 경로 목록을 저장한다. |
| PATH | 현재 폴더 | 현재 폴더는 지금 작업 중인 디렉터리이고, PATH는 명령어로 실행할 프로그램을 찾기 위해 검색하는 여러 디렉터리의 목록이다. |
| PATH | 실행 파일 | 실행 파일은 실제로 실행되는 프로그램이고, PATH는 운영체제가 그 실행 파일을 찾을 수 있도록 경로를 알려주는 값이다. |
| PATH | `cd` 명령어 | `cd`는 현재 작업 디렉터리를 이동시키는 명령이고, PATH는 실행 파일을 찾는 검색 경로를 지정한다. |

## 5. 많이들 오해하는 지점

### PATH가 프로그램 자체를 저장하는 곳이다?

PATH에는 프로그램이 들어 있는 것이 아니다.

PATH에는 **실행 파일을 찾기 위해 검색할 폴더의 경로**가 저장된다.

즉 PATH가 프로그램의 창고라면, 실제 프로그램은 그 창고에 있는 물건에 해당한다.

### 프로그램을 설치하면 무조건 PATH에 등록된다?

항상 그런 것은 아니다.

설치 프로그램이 PATH를 자동으로 설정해주는 경우도 있지만, 프로그램이나 설치 방식에 따라 직접 PATH를 수정해야 하는 경우도 있다.

그래서 프로그램은 분명 설치되어 있는데 터미널에서 명령어를 찾지 못하는 상황이 생길 수 있다.

### PATH에 프로그램 이름을 넣는 것이다?

PATH에는 일반적으로 `node.exe` 같은 실행 파일 이름이 아니라 **그 실행 파일이 들어 있는 디렉터리의 경로**가 들어간다.

예를 들어 Node.js 실행 파일이

`C:\Program Files\nodejs\node.exe`

에 있다면 PATH에는 보통

`C:\Program Files\nodejs\`

가 등록된다.

### PATH를 수정하면 프로그램이 이동하는 것이다?

PATH를 바꾼다고 프로그램의 위치가 이동하는 것은 아니다.

단지 운영체제에게 **“프로그램을 찾을 때 이 폴더도 확인해라”**라고 알려주는 것이다.
