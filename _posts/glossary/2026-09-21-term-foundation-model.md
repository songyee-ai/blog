## 한 줄 정의

> 남의 자료를 아주 많이 미리 배워 두어서, 내 일에는 새로 학습시키지 않거나 조금만 더 가르쳐 쓰는 모델

---

## 1. 비유로 이해하기

전학 온 친구를 떠올려 보자. 처음 보는 반인데도 하루 이틀이면 "이 반은 급식 줄을 번호순으로 서는구나", "숙제는 금요일에 걷는구나"를 금방 알아챈다. 이 반 규칙을 따로 배운 적은 없다. 그전에 다닌 학교 여러 곳에서 **학교라는 곳이 대강 어떻게 돌아가는지**를 이미 몸으로 익혀 두었기 때문이다.

반대로 학교를 처음 가 보는 아이는 줄 서기, 숙제 내기, 급식 먹기를 하나하나 새로 배워야 한다. 그리고 다른 학교로 옮기면 또 처음부터다.

기반 모델은 전학 온 친구 쪽이다. 여러 곳에서 넓게 배워 둔 덕에, 처음 보는 일도 조금만 보여 주면 알아듣는다. 전학생이 새 반에 오래 있으면서 그 반 방식에 더 익숙해지는 것처럼, 필요하면 내 자료로 조금 더 가르칠 수도 있다.

{% include figure.html src="/assets/images/term-foundation-model/train-each-vs-pretrain-once.svg" alt="왼쪽 예전 방식은 손바닥과 주먹, 컵과 병처럼 일이 바뀔 때마다 사진을 새로 찍고 처음부터 학습시켜 모델을 따로 만든다. 오른쪽 기반 모델은 남의 자료를 아주 많이 한 번 미리 배워 두고, 내 일에는 자료를 보여 주기만 하는 그대로 쓰기나 내 분야 자료로 조금 더 가르치는 이어 학습시키기로 쓴다" caption="그림 1. 일마다 처음부터 배우는 방식과, 한 번 넓게 배워 두고 여러 일에 쓰는 기반 모델" %}

실제로는, "미리 넓게 배운다"는 것은 모델 안의 숫자 뭉치({% include term.html name="파라미터" %})를 남의 자료 수백만~수억 건으로 한 번 맞춰 두는 일이다. 이 일은 만든 곳이 한 번 하고, 우리는 그 숫자 뭉치를 파일로 내려받아 쓴다.

## 2. 왜 필요한가

### 예전 방식에 붙어 오던 조건 셋

기반 모델이 무엇을 바꿨는지는 그전 방식을 떠올리면 잘 보인다. 수업에서 만진 Teachable Machine이 그 예전 방식이다.

| 예전 방식의 조건 | Teachable Machine에서 보면 | 기반 모델에서는 |
| --- | --- | --- |
| 내 자료로 학습해야 시작된다 | 사진을 한 장도 안 찍으면 학습 버튼이 안 눌린다 | 내 자료를 보여 주기만 해도 답이 나온다 |
| 자료가 적으면 흔들린다 | 반마다 두세 장이면 조명만 바꿔도 헷갈린다 | 스무 줄짜리 표로도 버틴다 |
| 일이 바뀌면 처음부터 | 손 모양 대신 컵과 병이면 새로 찍어 새로 학습 | 같은 모델에 다른 자료를 넣으면 된다 |

### 쓰는 길은 두 갈래

- **그대로 쓰기** — 모델은 손대지 않는다. 내 자료를 입력으로 보여 주면 그 자리에서 답한다. 학습 단계가 없다는 뜻에서 {% include term.html name="제로샷" %}이라고 부르고, 보여 준 자료를 참고해 답한다는 뜻에서 {% include term.html name="맥락 내 학습" %}이라고도 한다.
- **이어 학습시키기** — 이미 많이 아는 모델에게 내 분야 문제집 몇 권만 더 풀게 하는 쪽이다. 처음부터 가르치는 것에 비하면 자료도 시간도 훨씬 덜 든다. 세포 사진에서 세포 경계를 따는 **cellpose**가 좋은 예다. 만든 쪽이 범용 이미지 오려 내기 모델을 현미경 사진으로 한 번 더 다듬어 두었고, 나 같은 사용자는 다듬어진 결과물을 받아 손대지 않고 쓴다.

### 분야가 달라도 같은 모양

| 분야 | 예 | 미리 배운 것 | 내가 주는 것 |
| --- | --- | --- | --- |
| 시계열(날짜별 숫자) | Chronos | 전력·교통·환율 같은 온갖 숫자열 | 내 출고 기록 |
| 표 | TabICL | 규칙을 무작위로 지어 찍어 낸 가짜 표 수백만 개 | 내 스무 줄짜리 표 |
| 세포 상태 | Geneformer | 사람 세포 약 1억 개의 유전자 순위 | 내 실험 세포 몇백~몇천 개 |
| 세포 영상 | cellpose | 여러 종류의 현미경 사진 | 내 사진 한 장 |

챗봇에 쓰는 {% include term.html name="LLM" %}도 같은 계열이다. 인터넷 글을 잔뜩 미리 배워 두고, 우리는 질문만 넣는다.

### 조심할 것 셋

**크다고 더 잘 맞히지는 않는다.** 월별 항공 승객 수로 잰 결과에서 chronos-bolt-small(4,770만 개짜리)은 평균 오차 18.9, 네 배 넘게 큰 chronos-bolt-base는 22.3이었다. 자료가 짧으면 이런 일이 생긴다. 한 번 잰 값이라 법칙은 아니지만, "큰 거 받으면 된다"가 틀릴 수 있다는 건 보여 준다.

**남의 성적표는 부풀려져 있을 수 있다.** 기반 모델은 공개된 자료를 잔뜩 모아 배운다. 그런데 성능을 비교하는 시험 문제도 그 공개 자료에서 나오는 경우가 많다. 공부할 때 본 문제가 시험에 그대로 나오면 점수가 실력보다 높게 나오는 것과 같다. 이것을 **자료 유출(data leakage)**이라고 한다. 모델이 한 번도 못 본 것은 내 자료뿐이니, 내 자료로 잰 숫자를 믿는다.

**아주 단순한 방법과 꼭 나란히 놓는다.** "지난주 값을 그대로 다음 주에 적기" 같은, 모델이랄 것도 없는 방법을 **순진한 기준선**이라고 부른다. 모델 오차가 34라고만 들으면 잘한 건지 모른다. 기준선이 47이면 잘한 것이고, 기준선이 20이면 그 모델은 쓸 이유가 없다.

## 3. 어디서 만났나

**17회차**는 표·유전체·단백질·세포 영상 같은 여덟 갈래를 훑으면서, 그 밑에 깔린 발상 넷 중 첫째로 기반 모델을 꺼냈다. 시계열의 Chronos, 표의 TabICL, 세포의 Geneformer, 세포 영상의 cellpose가 모두 이 뼈대 위에 서 있다는 설명이었다.

나는 그중 Teachable Machine 실습을 했다. 손바닥과 주먹 두 가지를 찍어 학습시켰는데, 주먹을 다른 모양으로 쥐었을 때도, 각도가 달라져도 인식됐다. 이 실습은 기반 모델이 아니라 **내 자료로 학습해야 시작되는 예전 방식**을 직접 겪어 보는 자리였다.

## 4. 헷갈리는 개념

| 이 용어 | 비슷하지만 다른 것 | 차이 |
| --- | --- | --- |
| 기반 모델 | LLM | LLM은 글을 미리 배운 기반 모델의 한 종류. 기반 모델은 표·숫자열·세포·사진 쪽에도 있다 |
| 그대로 쓰기 | 이어 학습시키기 | 그대로 쓰기는 모델 속 숫자를 안 바꾸고 자료만 보여 준다. 이어 학습시키기는 내 자료로 숫자를 조금 고친다 |
| 기반 모델 | 처음부터 학습한 모델 | 처음부터 학습한 모델은 한 가지 일만 안다. 기반 모델은 넓게 배워 두어 여러 일에 가져다 쓴다 |
| 기반 모델 | 순진한 기준선 | 기준선은 모델이 아니라 비교용 자. 기반 모델이 쓸 만한지는 기준선과 나란히 놓아야 안다 |

## 5. 많이들 오해하는 지점

**ㄱ. "방대한 양의 레이블이 지정되지 않은 데이터로 사전 학습되어 다양한 다운스트림 작업에 맞게 조정할 수 있는 범용 인공지능 모델"**

수업 중에 내가 적어 둔 정의다. 틀린 말은 아닌데, 낱말이 어려워서 풀어 둔다.

- **레이블**은 "이 사진은 고양이"처럼 사람이 붙인 정답 딱지다. 딱지 없는 자료로 배운다는 건, 사람이 일일이 채점하지 않아도 자료 자체에서 문제를 만들어 배운다는 뜻이다. 문장의 다음 낱말 맞히기가 대표적이다.
- **다운스트림 작업**은 "미리 배우기가 끝난 뒤, 아래쪽(下流)에서 실제로 시키는 일"이다. 내 매출 예측, 내 부품 불량 가리기 같은 것.
- 한 가지 덧붙이면, **"조정할 수 있다"가 꼭 다시 학습시킨다는 뜻은 아니다.** TabICL이나 Chronos처럼 조정 없이 자료만 보여 주고 바로 쓰는 경우도 많다. 또 17회차의 TabICL은 사람이 모은 실제 자료가 아니라, 규칙을 지어 찍어 낸 가짜 표(정답까지 함께 만들어진 표)로 배웠다. 정의는 대표적인 모습을 말한 것이고, 모든 기반 모델이 똑같이 만들어지지는 않는다.

**ㄴ. "기반 모델이 나왔으니 예전 방법은 이제 필요 없다"**

17회차 표 실험에서 스무 줄로 TabICL은 AUC 0.9847, 그 스무 줄로 실제 학습시킨 랜덤 포레스트는 0.9813이었다. 거의 같다. 점수 차이로 보면 이긴 것도 진 것도 아니다. 달라진 건 **들인 품**이다. 한쪽은 학습을 돌렸고, 한쪽은 표를 넣었을 뿐이다. 자료가 넉넉해지면 익숙한 예전 도구로 충분하고, 자료가 적거나 규칙이 자주 바뀌면 단순한 기준선이 이기기도 한다.

**ㄷ. "클수록 좋은 모델이다"**

2절의 Chronos 결과처럼, 더 큰 모델이 더 많이 빗나간 경우가 있었다. 남의 순위표를 읽기보다 내 자료로 두세 개를 나란히 재 보는 편이 빠르고 정직하다.
