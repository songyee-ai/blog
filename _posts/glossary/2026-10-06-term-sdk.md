## 한 줄 정의

> 어떤 서비스나 플랫폼을 내 코드에서 쉽게 쓰도록 함수·문서·예제를 한데 묶어 준 개발용 꾸러미

---

## 1. 비유로 이해하기

멀리 사는 할머니께 편지를 보낸다고 해 보자. 우체국에는 정해진 규칙이 있다. 봉투 오른쪽 위에 우표, 가운데 받는 사람 주소, 왼쪽 위에 보내는 사람 주소, 우편번호는 다섯 자리. 이 규칙만 지키면 누구든 편지를 부칠 수 있다.

그런데 문방구에 **편지 쓰기 세트**가 있다. 주소 칸이 미리 인쇄된 봉투, 우표, 풀, 그리고 "여기에 이름을 쓰세요"라는 안내지까지 한 상자에 들어 있다. 세트를 쓰면 규칙을 하나하나 외울 필요 없이 칸만 채우면 된다.

{% include figure.html src="/assets/images/term-sdk/kit-and-window.svg" alt="왼쪽부터 내 코드, SDK, API, 서비스가 차례로 놓인 흐름. 내 코드는 SDK의 함수만 부르고, SDK가 API 규칙에 맞는 요청을 대신 만들어 서비스에 보낸다. SDK 상자 아래에는 이번 실습에서 열려 있던 옵션과 열려 있지 않던 옵션이 나뉘어 적혀 있다" caption="그림 1. SDK는 API 앞에 놓인 꾸러미 — 내 코드는 SDK가 열어 준 손잡이만 만진다" %}

- 우체국의 규칙 = {% include term.html name="API" %}
- 편지 쓰기 세트 = SDK

실제로는, SDK는 어떤 서비스(모델 서버, 결제, 지도 등)를 파이썬·자바스크립트 같은 특정 언어에서 부르기 쉽게 만든 **라이브러리와 문서, 예제의 묶음**이다. 안에서는 결국 그 서비스의 API 규칙에 맞는 요청을 만들어 보낸다. 나는 그 규칙을 직접 조립하는 대신 SDK가 준 함수를 부른다.

## 2. 왜 필요한가

### 직접 조립하기 vs 꾸러미 쓰기

로컬 {% include term.html name="Ollama" %} 서버에 "안녕"이라고 보내는 일을 두 가지로 해 볼 수 있다. 먼저 API 규칙대로 직접 요청을 조립하는 방법이다.

```python
import requests

url = "http://localhost:11434/api/chat"          # 서버 주소와 경로
body = {
    "model": "qwen3.5:2b",
    "messages": [{"role": "user", "content": "안녕"}],
    "stream": False,                              # 한 번에 통째로 받기
}
res = requests.post(url, json=body)               # 본문을 JSON으로 보냄
print(res.json()["message"]["content"])           # 응답 JSON에서 답 꺼내기
```

주소와 경로를 외우고, 본문을 규칙에 맞는 {% include term.html name="JSON" %} 모양으로 짜고, 응답의 어느 칸에 답이 있는지 찾는 일까지 다 내가 한다. 같은 일을 Ollama의 파이썬 SDK(`ollama` 패키지)로 하면 이렇게 줄어든다.

```python
import ollama

res = ollama.chat(model="qwen3.5:2b",
                  messages=[{"role": "user", "content": "안녕"}])
print(res["message"]["content"])
```

주소와 요청 모양은 SDK가 안다. 나는 "누구에게 무엇을 보낼지"만 적는다. 오류 처리, 스트리밍처럼 매번 손으로 짜기 귀찮은 부분도 SDK가 함수로 미리 만들어 두는 경우가 많다.

### SDK가 열어 준 손잡이만 돌릴 수 있다

편하다는 것은 곧 **SDK가 정해 준 범위 안에서만** 움직인다는 뜻이기도 하다. 편지 쓰기 세트에 빠른우편 스티커가 없으면, 세트만으로는 빠른우편을 부칠 수 없다.

20회차 실습에서 Claude Agent SDK(파이썬, 0.2.164)의 `query()` 로 모델을 불렀다. 이때 넘긴 옵션은 이랬다.

```python
options = ClaudeAgentOptions(
    model="haiku",
    system_prompt=instruction,
    tools=[], mcp_servers={}, strict_mcp_config=True,
    max_turns=1,
    setting_sources=[],
)
```

도구를 끄는 `tools=[]`, 한 번만 답하게 하는 `max_turns=1` 같은 손잡이는 있었다. 그런데 {% include term.html name="temperature" %}는 넘길 자리가 없었다(강의 설명으로는 {% include term.html name="top_k/top_p" %} 중 top_k도 마찬가지다). 그래서 실습 기록의 temperature 칸에는 숫자를 지어 넣지 않고 **"조절 불가"**라고 적었다. 같은 모델이라도 어떤 SDK, 어떤 함수로 부르느냐에 따라 조절할 수 있는 것이 달라진다. 이 범위는 버전마다 바뀔 수 있으니, 실험 전에 내가 쓰는 버전의 문서에서 확인한다.

### 기본값도 결과에 끼어든다

SDK는 내가 지정하지 않은 자리를 기본값으로 채운다. 그 기본값이 생각보다 많은 일을 할 수 있다.

같은 실습에서 `setting_sources=[]` 한 줄을 일부러 더했다. 기본값 그대로 두면 이 SDK가 내 컴퓨터(WSL)의 개인 설정 파일(`~/.claude/CLAUDE.md`)과 스킬까지 불러와 모델 입력에 섞는다는 것을 전날 실습에서 확인했기 때문이다. "지시문만 바꿔 비교한다"는 실험이 그 개인 설정 때문에 흐려지지 않게 막은 것이다.

### SDK에도 버전이 있다

SDK는 설치하는 패키지라서 버전이 붙는다. 이번 실습에서는 `uv run --with claude-agent-sdk` 로 실행했는데, 전날 0.2.163이던 SDK가 이날은 0.2.164로 새로 받아졌다. 버전에 따라 옵션 이름이나 기본값이 바뀔 수 있으니, 실험 기록에는 모델 이름과 함께 SDK 버전도 남겨 둔다.

## 4. 헷갈리는 개념

| 이 용어 | 비슷하지만 다른 것 | 차이 |
| --- | --- | --- |
| SDK | API | API는 **주고받는 규칙**(어디로, 어떤 모양으로 요청하면 무엇이 돌아오는지). SDK는 그 규칙을 특정 언어에서 쓰기 쉽게 감싼 **꾸러미**. API는 SDK 없이도 쓸 수 있다 |
| SDK | 라이브러리 | 라이브러리는 함수 묶음 하나. SDK는 보통 라이브러리에 문서·예제·도구까지 더한 더 큰 묶음이다. 실제로는 둘을 섞어 부르는 일이 많다 |
| SDK | CLI | {% include term.html name="CLI" %}는 터미널에 **명령어를 쳐서** 쓰는 프로그램, SDK는 **내 코드 안에서 함수로** 부르는 꾸러미. 같은 회사가 둘 다 내놓기도 한다 |
| Claude Agent SDK | 일반 모델 API용 SDK | 일반 SDK는 대개 요청 한 번 보내고 답 한 번 받는다. Agent SDK는 도구 사용·여러 턴 같은 **에이전트 동작**까지 감싸서, 그만큼 손잡이 구성이 다르다 |

## 5. 많이들 오해하는 지점

**ㄱ. "SDK를 쓰면 API는 안 쓰는 것이다"**

SDK는 API를 대신하는 게 아니라 **API 앞에 놓인 꾸러미**다. 함수 한 줄을 불러도, 원격 서비스라면 대개 SDK 안에서 API 요청이 만들어져 나간다. 그래서 API에서 오류가 나면 SDK를 써도 같은 오류를 만난다.

**ㄴ. "SDK로 부르면 서비스의 모든 기능을 다 쓸 수 있다"**

SDK가 열어 준 만큼만 쓸 수 있다. 이번 실습의 Claude Agent SDK `query()` 경로에서는 temperature를 넘길 자리가 없었다. 그 칸은 비워 두거나 기본값을 짐작해 적지 말고 "조절 불가"라고 기록한다.

**ㄷ. "옵션을 안 적으면 아무 일도 안 일어난다"**

안 적은 옵션은 **SDK의 기본값**으로 채워진다. 이번 실습에서는 기본값이 개인 설정 파일까지 입력에 섞을 수 있어서 `setting_sources=[]` 를 직접 적었다. 비교 실험을 할 때는 기본값이 무엇을 하는지부터 확인한다.
