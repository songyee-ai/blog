## 한 줄 정의

> 작은 필터를 그림 위로 미끄러뜨리며 무늬를 찾아내는 신경망. 합성곱 신경망

---

## 1. 비유로 이해하기

숨은그림찾기 책을 돋보기로 본다고 해 보자. 찾을 것은 "우산".

돋보기로는 그림의 **작은 부분만** 보인다. 그래서 왼쪽 위 구석부터 한 칸씩 옮겨 가며 훑는다. 돋보기를 댈 때마다 묻는 질문은 늘 같다. "여기 우산 손잡이처럼 휜 선이 있나?"

이때 중요한 점이 두 가지다.

- **돋보기는 하나다.** 왼쪽 위를 볼 때와 오른쪽 아래를 볼 때 다른 돋보기를 쓰지 않는다.
- **그래서 우산이 어디 숨어 있든 찾는다.** 구석에 있든 가운데 있든, 같은 돋보기에 같은 모양으로 보인다.

CNN이 그림을 보는 방식이 이것이다. 돋보기 역할을 하는 작은 숫자 묶음을 **필터**라고 부른다.

{% include figure.html src="/assets/images/term-cnn/filter-slide.svg" alt="6칸 곱하기 6칸 그림 위에 3칸 곱하기 3칸 파란 필터가 놓여 있고 아래로 한 칸씩 미끄러진다. 아래에는 낮은 층이 선과 모서리, 가운데 층이 곡선과 동그라미, 높은 층이 눈과 바퀴와 얼굴을 알아본다는 흐름이 있다" caption="그림 1. 필터 하나가 그림 전체를 훑고, 층을 쌓으면 작은 무늬가 큰 모양이 된다" %}

그래서 실제로는 이렇다. 컴퓨터에게 그림은 픽셀마다 밝기 숫자가 적힌 표다. 필터도 3×3 같은 작은 숫자 표다. 필터를 그림의 한 부분에 **겹쳐서 칸끼리 곱하고 모두 더하면** 숫자 하나가 나오는데, 그 부분이 필터가 찾는 무늬와 닮았을수록 크다. 이 "겹쳐 곱하고 더하기"가 **합성곱(convolution)**이고, CNN이라는 이름이 여기서 왔다. 무엇을 찾을지(필터 안의 숫자)는 사람이 정하지 않고 모델이 데이터를 보며 스스로 배운다.

## 2. 왜 필요한가

### 사람이 규칙을 짜던 시절의 한계

1990년대 후반 은행에서는 수표에 손으로 쓴 숫자를 기계가 읽게 하려 했다. 당시 방식은 사람이 먼저 "숫자 7은 위에 가로줄, 오른쪽에 비스듬한 줄" 같은 **특징을 손으로 정해 주는 것**이었다.

문제는 손글씨가 사람마다 제각각이라는 점이다. 미리 정한 규칙에서 조금만 벗어나도 기계가 못 읽었다.

CNN은 발상을 바꿨다. **특징을 사람이 정하지 말고, 픽셀에서 신경망이 직접 배우게 하자.** 이 방식은 손글씨 숫자를 안정적으로 읽어 냈고, 실제 수표 판독기로 상용화까지 됐다(1998년 논문).

### 같은 필터를 돌려 쓰면 외울 숫자가 확 준다

필터를 돌려 쓰는 게 왜 좋은지 숫자로 보자. 가로세로 100칸짜리 흑백 그림이라면 픽셀이 10,000개다.

```
방법 A: 픽셀마다 따로 숫자를 둔다
  → 무늬 하나를 찾는 데만 10,000개

방법 B: 3×3 필터 하나를 그림 전체에 돌려 쓴다
  → 무늬 하나를 찾는 데 9개
```

외워야 할 숫자(파라미터)가 줄면 적은 데이터로도 학습이 되고, 앞서 말한 대로 **무늬가 어느 위치에 있든 똑같이** 알아본다.

### 층을 쌓으면 작은 무늬가 큰 개념이 된다

필터를 한 번만 쓰는 게 아니라 여러 층으로 쌓는다. 앞 층이 찾은 결과 위에 다음 층이 또 필터를 댄다.

| 층 | 알아보는 것 | 비유 |
| --- | --- | --- |
| 낮은 층 | 선, 모서리, 색 | 레고 낱개 블록 |
| 가운데 층 | 곡선, 동그라미, 무늬 | 블록을 이은 바퀴·창문 |
| 높은 층 | 눈, 바퀴, 얼굴 | 다 조립한 자동차 |

### 2012년, 판을 뒤집다

1998년의 아이디어는 한동안 묻혀 있었다. 제대로 학습시킬 데이터와 계산력이 부족했기 때문이다. 14년쯤 지나 두 가지가 갖춰졌다. 라벨 붙은 이미지 수백만 장의 데이터셋, 그리고 대량 병렬 계산에 맞는 GPU다.

2012년 이미지 분류 대회에 나온 CNN(**AlexNet**)의 성적은 이랬다.

| 지표: top-5 오류율 | 값 |
| --- | --- |
| AlexNet (CNN) | **15.3%** |
| 같은 대회 2위 (기존 방식) | 26.2% |

top-5 오류율은 "모델이 내놓은 후보 다섯 개 안에 정답이 없는 비율"이다. 격차가 10%포인트를 넘었다. 이 모델에 들어간 재료는 다음과 같다.

- **ReLU** — 음수는 0으로, 양수는 그대로 내보내는 활성화 함수
- **드롭아웃** — 외우기를 막으려고 학습 때 뉴런 일부를 무작위로 끄는 방법(→ {% include term.html name="과적합" %})
- **GPU 두 장** — 파라미터 6천만 개를 학습시킨 장비

## 4. 헷갈리는 개념

| 이 용어 | 비슷하지만 다른 것 | 차이 |
| --- | --- | --- |
| CNN | 일반 신경망 (완전 연결) | 일반 신경망은 픽셀마다 따로 숫자를 둔다. CNN은 **작은 필터 하나를 돌려 쓴다** |
| 필터 | 사진 앱의 필터 | 사진 앱 필터는 사람이 만든 보정 효과. CNN 필터는 **모델이 배운 무늬 탐지기**다 |
| CNN | 트랜스포머 (ViT) | CNN은 "가까운 픽셀끼리 관련 있다"는 전제를 **설계에 품고** 있다. ViT는 그 전제 없이 모든 조각이 모든 조각을 보고, 대신 데이터가 훨씬 많이 필요하다 |
| CNN | MNIST | MNIST는 손글씨 숫자 **데이터셋**(시험지), CNN은 그걸 푸는 **모델 구조**(학생) |

## 5. 많이들 오해하는 지점

**ㄱ. "필터는 사람이 하나하나 설계한다"**

반대다. 사람이 특징을 짜 넣던 방식의 한계를 넘으려고 나온 게 CNN이다. 사람은 "3×3짜리 필터를 몇 개 쓴다" 같은 **틀만** 정하고, 필터 안의 숫자는 모델이 데이터를 보며 스스로 채운다.

그래서 학습이 끝난 뒤 필터를 들여다보면 가장자리 탐지기처럼 보이는 것들이 나오지만, 누가 그렇게 시킨 게 아니다.

**ㄴ. "CNN은 이제 옛날 기술이라 안 쓴다"**

2020년 ViT가 나온 뒤 트랜스포머 계열이 많은 분야에서 앞섰지만, 그건 **데이터가 충분히 많을 때** 이야기다. ViT는 3억 장 규모의 이미지로 사전학습한 뒤에야 CNN을 앞질렀다.

CNN은 "이웃 픽셀이 중요하다"는 지식을 설계로 공짜로 얻고 시작한다. 그래서 데이터가 적을 때는 여전히 유리할 수 있다. 사라진 기술이 아니라 **전제가 다른 선택지**다.

**ㄷ. "층을 계속 쌓으면 계속 좋아진다"**

2014년까지는 그래 보였다. 그런데 어느 선을 넘자 더 깊은 CNN이 얕은 것보다 **훈련 데이터에서마저** 못했다. 학습 신호가 앞쪽 층까지 도착하지 못하는 {% include term.html name="기울기 소실" %} 때문이었다.

이 벽은 층을 건너뛰는 지름길을 놓은 ResNet이 2015년에 넘었다. 깊이 자체가 답이 아니라, **깊어도 학습이 되게 하는 구조**가 답이었던 셈이다.
